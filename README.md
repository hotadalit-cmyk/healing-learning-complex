# ТОКОХОД — публичный сайт и MVP интерфейса сервиса

Frontend-прототип сайта ТОКОХОД для Великого Новгорода и демо-интерфейсов мастерской и клиентского кабинета. Публичная часть объясняет услуги, процесс приёмки, безопасность, QR-паспорта и B2B; заявки можно заполнить и сохранить в текущем браузере. Это не подключённый к рабочему сервису сайт.

## Запуск и проверки

```bash
npm install
npm run dev
```

```bash
npm run build
npx tsc --noEmit
npm run lint
```

## Маршруты

- `/` — публичная главная ТОКОХОД.
- `/services` — перечень услуг без неподтверждённых цен.
- `/service/e-scooters`, `/service/e-bikes`, `/service/monowheels` — страницы видов транспорта.
- `/b2b` — корпоративное обслуживание и форма запроса.
- `/booking` — заявка на сервис.
- `/faq`, `/contacts`, `/privacy`, `/warranty` — вопросы, контакты, черновик политики и информация о гарантийных документах.
- `/qr/:qrId` — общедоступный QR-паспорт с ограниченными сведениями; персональные данные, стоимость и история ремонта не показываются.
- `/status/:orderId`, `/estimate/:orderId` — демо-страницы статуса и сметы.
- `/client` — клиентский PWA-кабинет. Код `0000` — только демонстрационный OTP, не проверка личности.
- `/workshop` — демо-панель мастерской. Старый `/public` перенаправляется на `/`.

## Демо-формы и конфигурация

Форма B2C локально создаёт запись заявки и карточку клиента; B2B-форма создаёт локальный запрос. Они видны в `/workshop` в том же браузере. Фиксируются время, источник, URL без query-строки, очищенные от email/телефоноподобных значений UTM-метки, канал связи и версия согласия. В CRM есть локальный индикатор новых заявок. Он не доставляет уведомление оператору и не синхронизирует данные между браузерами.

Выбранные изображения **не загружаются**: в демо сохраняются только имена файлов, а в карточке они отделены от фотографий приёмки. Локальная аналитика хранится только в localStorage; внешняя аналитика не подключена.

Подтверждённые контакты, адрес, часы, маршрут и карта задаются в `src/lib/publicSite.ts` в `publicContactConfig`. Сейчас эти поля намеренно пустые. Изображение мастерской — нейтральная сгенерированная иллюстрация, не фотография фактического сервиса. Страницы `/privacy` и `/warranty` содержат явно обозначенные черновики/ограничения и требуют проверки перед публикацией.

## Границы прототипа и безопасности

Нет backend/API, базы данных, серверной авторизации и ролевой изоляции, реальной отправки уведомлений, серверного антиспама, загрузки файлов, хранилища документов, подтверждённого адреса/карты, интеграции с SMS/Telegram или внешнего аналитического сервиса. Проверка формы, consent storage, rate limit, роли и QR/клиентские маршруты работают в браузере; это не защита реальных данных. **Не вводите реальные персональные данные и не используйте демо для приёма реальных заказов.**

Публичные контакты, цены, отзывы, часы, гарантийные обязательства, сроки и B2B SLA не заполняются демонстрационными сведениями. Условия для конкретной работы должны быть подтверждены и указаны в документе заказа. QR-страница не раскрывает владельца. При признаках риска батареи используется формулировка из утверждённой памятки: не использовать и не заряжать устройство до осмотра; точную оценку проводит мастер ТОКОХОД.

PWA остаётся веб-приложением; App Store/Google Play, прокат, GPS/геозоны, дистанционная блокировка и инструкции по вскрытию или ремонту повреждённых аккумуляторов не входят в объём.
